Run each configuration example in a fresh Python session. These examples run
without model data. For complete parsing,
translation, and export, use the linked workflow guides.

These public functions operate on parsed `r2x_core.System` objects.
They translate components and attach time series; the target exporter writes the native model files.
For command-line execution, follow the [CLI tutorial](/R2X/tutorials/reeds-to-sienna-cli/).

## Translation functions

### `reeds_to_plexos`

[View function source →](https://github.com/NatLabRockies/R2X/blob/19885442e37cdd4951dd64a693ea590b0f8c83e3/packages/r2x-reeds-to-plexos/src/r2x_reeds_to_plexos/translation.py#L22-L57)

```text
reeds_to_plexos(system: System, config: ReedsToPlexosConfig) -> System
```

Translate ReEDS components to PLEXOS and attach reserve, generator, region-load, and purchaser time series.

| Parameter | Contract |
| --- | --- |
| `system` | Parsed ReEDS system containing the components and time series expected by the [workflow](/R2X/how-to/reeds-to-plexos/). |
| `config` | `ReedsToPlexosConfig`. See the configuration fields below. |

Returns a new PLEXOS system with the translated components and attached time series.
Input time-series storage is reused by the target system. The default hydro budget resolution is daily.
Missing required input data or invalid mapping/configuration values can raise errors during rule application or post-processing.

```pycon
>>> from r2x_reeds_to_plexos.plugin_config import ReedsToPlexosConfig
>>> config = ReedsToPlexosConfig()
>>> assert config.hydro_budget_ts == 'daily'
```

```text
reeds_to_sienna(system: System, config: ReEDSToSiennaConfig) -> System
```

Translate ReEDS components to Sienna, normalize generator active-power profiles, attach pumped-hydro inflow, and add generator emissions.

| Parameter | Contract |
| --- | --- |
| `system` | Parsed ReEDS system containing the components and time series expected by the [workflow](/R2X/how-to/reeds-to-sienna/). |

Returns a new Sienna system with the translated components and attached time series.

Missing required input data or invalid mapping/configuration values can raise errors during rule application or post-processing.


### `sienna_to_plexos`

[View function source →](https://github.com/NatLabRockies/R2X/blob/19885442e37cdd4951dd64a693ea590b0f8c83e3/packages/r2x-sienna-to-plexos/src/r2x_sienna_to_plexos/translation.py#L37-L86)

```text
sienna_to_plexos(system: System, config: SiennaToPlexosConfig) -> System
```

Translate Sienna components to PLEXOS, resolve conflicting source components, consolidate zones, attach time series, and establish the target memberships.

| Parameter | Contract |
| --- | --- |
| `system` | Parsed Sienna system containing the components and time series expected by the [workflow](/R2X/how-to/sienna-to-plexos/). |
| `config` | `SiennaToPlexosConfig`. See the configuration fields below. |

Returns a new PLEXOS system with the translated components and attached time series.
The translation also applies the package's exporter patches and resolves source conflicts. Use a separate loaded system if you need an untouched source.
Missing required input data or invalid mapping/configuration values can raise errors during rule application or post-processing.

```pycon
>>> from r2x_sienna_to_plexos.plugin_config import SiennaToPlexosConfig
>>> config = SiennaToPlexosConfig()
>>> assert config.hydro_budget_ts == 'weekly'
```
